# Parche Dev 2026

Sitio oficial del encuentro Parche Dev 2026, construido solo con HTML semántico.
Reto individual del Módulo 1 · HTML y CSS, RIWI.

Sitio publicado: https://ronald0226.github.io/parche-dev/

## Páginas

- Inicio
- Agenda
- Ponentes
- Inscripción y confirmación
- Código de conducta

## Cómo verlo en tu computador

1. Clona el repositorio.
2. Ábrelo en VS Code.
3. Abre index.html con Live Preview.

## Decisiones que tomé

- Usé `<header>` para identificar la cabecera común del sitio.
- Usé `<nav>` para organizar los enlaces de navegación.
- Usé `<main>` para separar el contenido principal de cada página.
- El formulario usa el método GET, que muestra los datos enviados en la URL. Los espacios y caracteres especiales pueden codificarse en la dirección.
- GET no es adecuado para contraseñas ni datos sensibles, porque la información puede quedar visible en la URL.
## Lo que aprendí

- Aprendí a organizar páginas con HTML semántico.
- Aprendí a crear enlaces entre páginas.
- Aprendí a validar el código HTML y corregir errores.
