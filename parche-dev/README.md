
# Parche Dev

Encuentro de desarrolladores en Medellín para aprender, compartir conocimientos y conectar con la comunidad.

## Fecha y lugar

- **Fecha:** 5 de diciembre de 2026.
- **Horario:** 8:00 a. m. a 3:00 p. m.
- **Lugar:** Auditorio Casa Nodo.
- **Entrada:** Gratuita.

## Páginas del proyecto

- `index.html`: página de inicio.
- `agenda.html`: agenda de actividades.
- `ponentes.html`: información de los ponentes.
- `inscripcion.html`: formulario de inscripción.
- `gracias.html`: confirmación de inscripción.
- `conducta.html`: código de conducta.
- `404.html`: página de error.

## Tecnologías

- HTML5.
- Git y GitHub.

## Autoría

Proyecto educativo desarrollado como parte del proceso de aprendizaje en desarrollo web.
